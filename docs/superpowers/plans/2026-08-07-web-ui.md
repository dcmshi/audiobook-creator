# Web UI Implementation Plan (Plan 3 of 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A localhost web UI (`abc serve`) over the existing job engine: drag-drop a file, pick mode/voice/privacy, watch per-stage progress live, edit processed text in the browser, re-synthesize, play/download the result.

**Architecture:** FastAPI app in `audiobook_creator/web/` sharing the CLI's `jobs/` directory and engine — the web layer only reads/writes the same file contracts. Pipeline runs execute in a single background worker thread per process (`ThreadPoolExecutor(max_workers=1)`; the pipeline is process-wide sequential by design — GPU/CPU bound). Progress streaming is server-sent events fed by polling `job.json` (the file contract IS the state store; no new state introduced). Frontend is ONE static `index.html` with vanilla JS — no build chain, no framework, no CDN.

**Tech Stack:** FastAPI + uvicorn + python-multipart (new deps), stdlib threading, EventSource/fetch in the browser.

**Plan sequence:** Plan 3 of 3, after Plan 2 (`docs/superpowers/plans/2026-08-07-llm-layer.md`). The UI must not require Plan 2's LLM features to run (verbatim works with zero config), but exposes mode selection that Plan 2 unlocked. Spec: `docs/superpowers/specs/2026-08-06-audiobook-creator-design.md` (§ Job model and frontends).

## Global Constraints

- All Plan 1/2 constraints bind (utf-8, pathlib, hermetic tests, pinned ruff, strict markers, commit prefixes).
- **Localhost only, single user, no auth** (spec v1): uvicorn binds `127.0.0.1` — never `0.0.0.0`.
- The web layer NEVER bypasses the file contracts: no in-memory job state that `abc jobs` can't see; everything derives from `jobs/<id>/`.
- Uploaded files are stored inside the job dir (`jobs/<id>/source/<name>`), filename passed through `safe_filename`; path traversal in any `{job_id}` or filename route segment must 404 (validate `job_id` matches `^[0-9a-f]{8}$`; downloads resolve within `output/` and reject escapes).
- Tests use FastAPI's `TestClient` with the `stub` TTS backend and a temp jobs dir — no server process, no network, no model weights. The background executor is exercised synchronously in tests via dependency override.
- SSE endpoint must terminate: it closes after the job reaches a terminal state (all stages done, or any failed) or the client disconnects.

```python
# src/audiobook_creator/web/runner.py
import logging
from collections.abc import Callable
from concurrent.futures import ThreadPoolExecutor

logger = logging.getLogger(__name__)


class JobRunner:
    def __init__(self) -> None:
        self._pool = ThreadPoolExecutor(max_workers=1, thread_name_prefix="abc-pipeline")
        self._active: set[str] = set()

    def submit(self, job_id: str, fn: Callable[[], None]) -> None:
        self._active.add(job_id)

        def wrapped() -> None:
            try:
                fn()
            except Exception:  # noqa: BLE001 - job.json carries the failure; UI reads it there
                logger.exception("pipeline run for job %s failed", job_id)
            finally:
                self._active.discard(job_id)

        self._pool.submit(wrapped)

    def is_active(self, job_id: str) -> bool:
        return job_id in self._active

    def shutdown(self) -> None:
        self._pool.shutdown(wait=False, cancel_futures=True)
```

```python
# src/audiobook_creator/web/app.py  (Task 1 slice)
import re
from pathlib import Path

from fastapi import FastAPI, HTTPException

from audiobook_creator.core.job import Job
from audiobook_creator.web.runner import JobRunner

_JOB_ID = re.compile(r"^[0-9a-f]{8}$")


def _load_or_404(jobs_dir: Path, job_id: str) -> Job:
    if not _JOB_ID.fullmatch(job_id):
        raise HTTPException(status_code=404, detail="unknown job")
    try:
        return Job.load(jobs_dir, job_id)
    except (FileNotFoundError, ValueError) as exc:
        raise HTTPException(status_code=404, detail="unknown job") from exc


def create_app(jobs_dir: Path, runner: JobRunner | None = None) -> FastAPI:
    app = FastAPI(title="audiobook-creator")
    app.state.jobs_dir = jobs_dir
    app.state.runner = runner or JobRunner()

    @app.get("/api/jobs")
    def list_jobs() -> list[dict]:
        rows: list[dict] = []
        for job_id in Job.list_ids(jobs_dir):
            try:
                job = Job.load(jobs_dir, job_id)
            except (OSError, ValueError):
                rows.append({"id": job_id, "corrupt": True})
                continue
            rows.append({
                "id": job_id,
                "source": job.state.config.source,
                "mode": job.state.config.mode.value,
                "stages": {k: v.value for k, v in job.state.stages.items()},
                "errors": job.state.errors,
                "has_output": any(job.output_dir.glob("*.m4b")) or any(job.output_dir.glob("*.mp3")),
            })
        return rows

    @app.get("/api/jobs/{job_id}")
    def get_job(job_id: str) -> dict:
        job = _load_or_404(jobs_dir, job_id)
        return {
            **job.state.model_dump(mode="json"),
            "processed": sorted(p.name for p in job.processed_dir.glob("*.txt")),
            "outputs": sorted(p.name for p in job.output_dir.iterdir()
                              if p.suffix in (".m4b", ".mp3", ".wav")),
            "active": app.state.runner.is_active(job_id),
        }

    @app.on_event("shutdown")
    def _shutdown() -> None:
        app.state.runner.shutdown()

    return app
```
